About
I'm a B.Tech Computer Science student at UPES (Class of 2028) who enjoys taking software from an initial idea to a working deployment. My main interests are Java backend development, API design, authentication and authorization, databases, cloud infrastructure, and DevOps.

Alongside coursework and DSA practice, I'm building a mobility product as Founder & CEO of Vallo and developing ForgeOps-AI, an open-source DevOps decision-support platform.

I care about practical engineering: clear architecture, maintainable code, safe defaults, testing, and understanding what actually happens when a service fails.
Featured work
01 — ForgeOps-AI · Open source
DevOps troubleshooting, infrastructure templates, and operational safety in one workspace.
- Analyze pasted CI/CD logs and Docker/Kubernetes events to surface potential failure causes and remediation steps.
- Generate reviewable Terraform, Kubernetes, Docker, and CI/CD configuration templates.
- Review potentially risky shell commands before an operator takes action; generated commands are not automatically executed.
- Built with Java, Spring Boot, React, TypeScript, PostgreSQL, and Redis; deployed as a containerized demo on AWS EC2.
- Includes JWT-based authentication, automated tests, CI workflows, security scanning, and optional observability tooling.
The published demo currently uses a local DevOps rules engine; Gemini is an optional integration when configured. Some newer governance features in the source code are not yet deployed to the public demo.
